# Карантин несовместимых модов запуска

Здесь лежат исходные CurseForge-файлы, которые сохранены для возможного восстановления, но не загружаются Forge.

## Just Enough Resources 1.4.0.247

- исходный файл: `JustEnoughResources-1.20.1-1.4.0.247.jar`;
- источник: CurseForge file ID `5057220`;
- причина карантина: в пользовательском world-smoke логе от 9 августа 2026 года JEI-плагин JER завершал `registerCategories` с `ExceptionInInitializerError`; корень — `Unreferenced key` для динамического биома `nuclearcraft:wasteland`;
- эффект: вкладки JER не регистрировались, поэтому обучение этой функции было бы ложным;
- замена в книге: JEI для рецептов, Jade для блока перед игроком, наблюдение жил и квестовая геология для фактической генерации GTCEu;
- восстановление: вернуть JAR в `mods/` только после появления совместимой версии и повторного пользовательского smoke-теста. Одновременное хранение копии здесь и в `mods/` запрещено.

Minecraft при помещении файла в карантин не запускался.
