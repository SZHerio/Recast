# Выгрузки из работающей игры

Папка нужна, чтобы скрипты могли писать сюда файлы: `JsonIO.write` не создаёт
каталог сам и падает с `NoSuchFileException`, если его нет.

Здесь появляется `gtceu_item_census.json` — список настоящих ID предметов
GregTech, снятый с живого реестра при загрузке мира. Он нужен потому, что
GregTech регистрирует свои предметы в рантайме, и выдумывать их ID запрещено
правилами сборки.

Файлы отсюда являются входными данными для авторской работы, а не игровым
содержимым. Удалять их безопасно: они появятся снова при следующем входе в мир.
