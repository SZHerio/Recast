Сведения о каталоге:

assets — работает как resource pack; сюда можно класть клиентские ресурсы, например текстуры, модели и т. д. Пример: assets/kubejs/textures/item/test_item.png
data — работает как datapack; сюда можно класть серверные ресурсы, например таблицы лута, функции и т. д. Пример: data/kubejs/loot_tables/blocks/test_block.json

startup_scripts — скрипты, которые загружаются один раз при старте игры. Используются для добавления предметов и других вещей, которые могут происходить только во время загрузки игры (можно перезагрузить через /kubejs reload_startup_scripts, но это может не сработать)
server_scripts — скрипты, которые загружаются при каждой перезагрузке серверных ресурсов. Используются для изменения рецептов, тегов, таблиц лута и обработки событий сервера (можно перезагрузить через /reload)
client_scripts — скрипты, которые загружаются при каждой перезагрузке клиентских ресурсов. Используются для событий JEI, подсказок и других клиентских вещей (можно перезагрузить через F3+T)

config — хранилище конфигурации KubeJS. Это также единственный каталог, к которому скрипты могут обращаться, кроме каталога мира
exported — сюда попадают выгрузки данных, например атласы текстур

Типовые журналы можно найти в каталоге logs/kubejs/
