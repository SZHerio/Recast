# Recast

Экспертная сборка Minecraft 1.20.1 на Forge 47.4.22. Путь от полевого лагеря до
межпланетной промышленности через десять эпох. Русский язык — основной.

Внутренний идентификатор пространства имён — `industrial_frontier`. На нём
завязаны все реестры, и он не переименовывается; «Recast» — отображаемое имя.

## Установка

**Способ первый, прямой.** Скачать архив, распаковать и положить папку в
`…\curseforge\minecraft\Instances\`. Экземпляр появится в CurseForge App как
обычный: моды, конфигурации, квесты и книга уже внутри.

**Способ второй, через импорт.** Для сборки импортируемого zip нужен
[`manifest.json`](manifest.json) — в нём перечислены 113 модов с точными
project/file ID, и CurseForge скачивает их сам.

Одно исключение в обоих случаях: **CC: Tweaked 1.120.0**. Мод перестал
публиковаться на CurseForge, поэтому в манифесте его нет, и он лежит в `mods/`
напрямую. Решение и его причина записаны в
[`docs/registries/curseforge_sources.json`](docs/registries/curseforge_sources.json).

## Проверки

Три скрипта, которые запускаются после любого изменения. Minecraft они не
запускают.

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\lint_content.ps1 -NodePath "путь\к\node.exe"
```

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\validate_m2_architecture.ps1
```

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\audit_instance.ps1
```

Требование — ноль ошибок. Два предупреждения валидатора о NuclearCraft и HBM
ожидаемы: это зарегистрированное отклонение, оба мода установлены раньше своей
волны и до неё не получают ни рецептов, ни квестов.

## Состояние

Этапы M0–M5 закрыты: 63 пункта плана, открытых нет. Готовность считается
построчно по [`docs/registries/milestone_status.json`](docs/registries/milestone_status.json),
а не на словах — почему именно так, написано в
[`docs/REPORTING_RULES.md`](docs/REPORTING_RULES.md).

История сборок — [`docs/VERSION_LOG.md`](docs/VERSION_LOG.md).

## Содержимое и права

Авторская часть — скрипты, конфигурации, квесты, тексты, реестры и инструменты —
написана для этого проекта. Моды в `mods/` принадлежат своим авторам и включены
для воспроизводимости приватного экземпляра; их происхождение с точностью до
файла и SHA-256 зафиксировано в реестре источников.
