# Threat Director

Статус M1: **спецификация и схемы, не исполняемый мод**.

Threat Director станет единственным серверным владельцем технологической эпохи, репутации, принадлежности, договоров, фактов, баз и жизненного цикла операций. Он не заменяет FTB Quests, Easy NPC, TACZ: NPCs, In Control! или оружейные моды; он выдаёт им безопасные решения и принимает валидируемые намерения.

JAR не создаётся и не помещается в `mods/`, пока проект не получит:

- mod ID `industrial_frontier_threats`;
- Java package `dev.industrialfrontier.threats`;
- Forge MDK `47.4.22`;
- тесты миграции SavedData;
- отдельный CurseForge-проект и exact file ID;
- пользовательский server/client gate.

Сюжетные диалоги на M1 не написаны.
