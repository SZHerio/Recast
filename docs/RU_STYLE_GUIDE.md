# Русский style guide и глоссарий

Версия: `1.1` для `IF-M2-0001`.

## Голос книги

Квестбук говорит с игроком как спокойный инженер-наставник. Он объясняет причинно-следственную связь и не прячет критические условия за шуткой.

- Обращение: на «вы», без канцелярита.
- Предложения короткие; один абзац — одна мысль.
- Сначала цель и принцип, затем точные действия.
- Название элемента интерфейса приводится так, как оно отображается в игре.
- Формулы, единицы и диапазоны пишутся явно.
- «Сделайте что-нибудь и разберитесь» запрещено.
- Если действие опасно, предупреждение идёт **до** действия.
- Если есть несколько способов, книга называет рекомендуемый и объясняет альтернативы.

Каждый обучающий квест по механизму содержит: назначение → предпосылки → принцип → сборку → интерфейс → безопасный запуск → ожидаемый результат → диагностику → автоматизацию → межмодовое применение.

### Термины Applied Energistics 2

Руководство GuideME, будущая квестовая глава и Paxi-overlay используют один словарь. Аббревиатура **МЭ** пишется кириллицей в видимых русских названиях; resource ID и имена API не переводятся. В составных названиях перед нарицательным словом ставится дефис: `МЭ-сеть`, `МЭ-шина`, `МЭ-порт`, `МЭ-терминал`, `МЭ-поставщик`.

| English | Нормативный русский | Примечание |
|---|---|---|
| ME network | МЭ-сеть | Прилагательное: «сетевой»; не «сетка» |
| device | устройство | В контексте каналов — блок, потребляющий канал |
| channel | канал | Число занятых/доступных каналов указывается явно |
| subnetwork | подсеть | Отдельная МЭ-сеть, связанная ограниченным интерфейсом |
| storage cell | ячейка хранения | Не «камера хранения» |
| cell workbench | верстак для ячеек | Собственное игровое имя синхронизируется overlay |
| storage component | компонент хранения | Размеры в русском тексте: 1К, 4К, 16К, 64К, 256К |
| type | тип | Отдельный уникальный вид предмета/жидкости в ячейке |
| byte | байт | Единица внутренней ёмкости AE2, не реальный объём памяти |
| import / export / storage bus | шина импорта / экспорта / хранения | Направление объясняется относительно МЭ-сети |
| interface | МЭ-интерфейс | Не смешивать с поставщиком шаблонов |
| pattern provider | поставщик шаблонов | Передаёт ингредиенты машине или сборщику |
| molecular assembler | молекулярный сборщик | Выполняет обычные шаблоны изготовления |
| autocrafting | автоматическое изготовление | «Автокрафт» допустим лишь как поисковый синоним |
| crafting CPU | процессор изготовления | Вся многоблочная установка, не только один блок |
| crafting storage | хранилище для изготовления | Определяет максимальный размер задания |
| co-processing unit | сопроцессор | Позволяет выполнять больше операций параллельно |
| terminal | терминал | Вид терминала уточняется полным игровым названием |

| spatial I/O | пространственный ввод-вывод | Не переводить I/O как пользовательский «ввод текста» |

Если встроенный `ru_ru` AE2 расходится с этим словарём, перевод руководства не подстраивается под ошибку: соответствующий видимый ключ заносится в редакторский Paxi-overlay, после чего отчёт локализации пересобирается.

## Химические тексты

- В первом упоминании: полное русское название и формула, например «серная кислота (H₂SO₄)».
- Агрегатное состояние и чистота указываются, когда влияют на рецепт.
- Мольные соотношения не заменяются произвольным игровым числом без пояснения масштаба.
- Опасности описываются конкретно: токсичность, коррозионность, воспламеняемость, давление, радиация.
- Цвет не является единственным способом различить реагенты.
- «Химикат», «кислота» и «газ» не используются вместо точного вещества.

## Локализационная дисциплина

1. Любой новый пользовательский ключ одновременно появляется в `ru_ru` и `en_us`.
2. Русский и английский тексты редактируются отдельно; одинаковая структура ключей не означает буквальный перевод.
3. В обязательной русской книге нет временных английских заглушек.
4. Неизвестный официальный термин заносится в этот глоссарий до массового использования.
5. Скрипт `tools/lint_content.ps1` проверяет паритет ключей авторского namespace.
6. `tools/audit_instance.ps1` формирует backlog отсутствующих переводов сторонних модов; наличие backlog блокирует финальный релиз, но не мешает поэтапному M1-тесту.
