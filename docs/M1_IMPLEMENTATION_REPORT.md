# M0–M1: отчёт о реализации

Build ID: **`IF-M1-0001`**  
Дата: **2 августа 2026 года**  
Статус: **`STATIC_COMPLETE / USER_GATE_PENDING`**  
Minecraft со стороны Codex: **не запускался**

## 1. Что собрано

M0 зафиксировал воспроизводимую платформу, владельцев систем и ограничения интеграции. M1 добавил рабочий авторский слой для рецептов, квестов, обучающих сцен, packs, лута, русификации и будущего внешнего мира. Это не «демо всей сборки», а фундамент, на котором дальнейшие эпохи можно менять без хаотичных ID, дублирующих систем и ручного редактирования десятков несвязанных файлов.

Статическая часть завершена. Статус не меняется на `ACCEPTED`, пока владелец не выполнит короткий игровой gate по [`BUILD_TEST_PROTOCOL.md`](BUILD_TEST_PROTOCOL.md).

## 2. Решения M0

### Платформа и идентичность

- Minecraft `1.20.1`, Forge `47.4.22`.
- Базовая Java `17`; Java `21` допускается только как явно записанный пользовательский compatibility-gate.
- Постоянный технический namespace: `industrial_frontier`.
- Рабочее отображаемое имя: **Recast**; ребрендинг не меняет ID.
- Основной язык: русский. Английские тексты создаются отдельно, а не служат шаблоном буквальной кальки.
- Средний уровень гринда закреплён как измеряемое ограничение, а не пожелание.

Подробности: [`M0_PLATFORM_LOCK.md`](M0_PLATFORM_LOCK.md), [`GRIND_POLICY.md`](GRIND_POLICY.md), [`RU_STYLE_GUIDE.md`](RU_STYLE_GUIDE.md).

### Происхождение модов

В активном профиле находится **51 JAR**. Для каждого известны CurseForge project/file ID и допустимый CurseForge CDN URL, а полный текущий SHA-256 записан в lock-файле. Прямые установки M0–M1 сверяются с закреплённым SHA-256 exact-файла; записи, полученные из CurseForge App, — с опубликованным SHA-1 или MD5 из его манифеста. Все новые сторонние JAR скачаны только из точных файлов CurseForge. Видимость внутри CurseForge App не требуется и `minecraftinstance.json` не является единственным источником истины.

Источники и машинные снимки:

- [`registries/curseforge_sources.json`](registries/curseforge_sources.json) — exact-file registry прямых установок;
- [`registries/generated/IF-M1-0001/mod_manifest_lock.json`](registries/generated/IF-M1-0001/mod_manifest_lock.json) — все активные JAR и их хэши;
- [`registries/generated/IF-M1-0001/dependency_audit.json`](registries/generated/IF-M1-0001/dependency_audit.json) — поставщики и обязательные диапазоны.

### Закрытые блокеры

- Добавлен Citadel `2.6.3` для Alex’s Mobs `1.22.9`.
- JEI обновлён с `15.20.0.112` до `15.20.0.134`, удовлетворяя требованию GTCEu `7.5.3` `>=15.20.0.115`.
- Старый JEI сохранён восстанавливаемо в `backups/IF-M1-0001/mods/`, но не остаётся активным.

### Владение ресурсами и энергией

- GTCEu — единственный текущий владелец рудной генерации; worldgen Create выключен.
- Biomes O’ Plenty + TerraBlender назначены целевым биомным профилем, но ставятся отдельной волной перед созданием постоянного мира.
- SU, EU, FE и будущая HBM-энергия остаются разными доменами.
- На текущем срезе разрешён только экспорт GT EU → FE с коэффициентом `1 EU = 4 FE`; двусторонние GT-конвертеры выключены.
- Пар и тепло считаются предпочтительными физическими мостами между промышленными доменами.

## 4. Архитектура авторского слоя

```text
authoring/ (редактируемые источники и схемы)
        ↓ compile/ручная синхронизация с trace
config/ftbquests + kubejs/ + config/paxi/ (игровое представление)
        ↓ audit + lint
docs/registries/generated/IF-M1-0001/ (воспроизводимый снимок)
```

### Источники и стабильные ID

- [`authoring/README.md`](../authoring/README.md) описывает границу source/compiled.
- [`registries/stable_ids.json`](registries/stable_ids.json) хранит постоянные FTB и resource ID.
- [`registries/retired_ids.json`](registries/retired_ids.json) не позволяет переиспользовать удалённый ID с новым смыслом.
- JSON Schema в `authoring/schemas/` задают форму квестов, Ponder и Easy NPC sandbox.
- [`authoring/trace/m1_trace.json`](../authoring/trace/m1_trace.json) связывает источники с игровыми файлами.

### Квестовая книга

Созданы **14 русских квестов** в двух главах:

1. **«Начать здесь»** — 7 последовательных квестов: правила книги, JEI, командный прогресс, эквивалентность тегов, эталонный рецепт партии и переход к следующей главе.
2. **«Помощь и восстановление»** — 7 необязательных диагностических квестов: JEI, незасчитанный предмет, команда, `latest.log`, полезный отчёт и безопасное восстановление.

Эталонный урок использует схему **контекст → подготовка → действие → признак успеха → причина → автоматизация → диагностика → следующий шаг**. Никаких наград, поглощения предметов, таймеров и искусственного повторения в M1 нет.

Игровые файлы: [`00_start_here.snbt`](../config/ftbquests/quests/chapters/00_start_here.snbt) и [`90_help.snbt`](../config/ftbquests/quests/chapters/90_help.snbt). Редактируемые источники находятся в [`authoring/quests/`](../authoring/quests/).

Задание на восемь брёвен использует `ftbfiltersystem:smart_filter` и pack-тег `industrial_frontier:materials/wood_logs`, который наследует `#minecraft:logs`. Формат NBT и выражения фильтра дополнительно сверяется с установленным JAR; окончательное распознавание остаётся пунктом пользовательского smoke-теста.

### Рецепты и лут

- `industrial_frontier:m1/bulk_chest_from_logs`: 8 любых брёвен → 4 сундука. Материальный выход равен четырём ванильным крафтам, но убирает повторные ручные операции.
- `industrial_frontier:m1/create/batch_clay_block`: 4 комка глины → 1 блок глины в Create mixer. Это безопасный интеграционный smoke-рецепт без ускорения прогрессии.
- LootJS регистрирует намеренно пустой M1-hook и не меняет существующий лут.

Файлы: [`m1_bulk_storage.js`](../kubejs/server_scripts/00_core/recipes/m1_bulk_storage.js), [`m1_create_integration.js`](../kubejs/server_scripts/00_core/recipes/m1_create_integration.js), [`m1_lootjs_smoke.js`](../kubejs/server_scripts/00_core/loot/m1_lootjs_smoke.js).

### Обучающая сцена

Для `create:basin` создана русская Ponder-сцена **«Партия, буфер и узкое место»**. Она показывает входной буфер, mixer/basin, выходной буфер и причину остановки линии. Это шаблон будущих промышленных уроков, а не декоративная анимация.

Файлы: [`m1_batch_processing.js`](../kubejs/client_scripts/10_ponder/m1_batch_processing.js) и [`authoring/ponder/m1_batch_processing.json`](../authoring/ponder/m1_batch_processing.json).

### Внешний мир без преждевременного контента

Threat Director пока существует только как спецификация данных и API:

- один авторитетный `industrial_frontier:tech_epoch`, P0–P9;
- `epoch_floor` только для защиты миграций, не второй прогресс;
- репутация отдельно от принадлежности;
- договоры, факты, базы B0–B6, операции и их конечный lifecycle;
- read-only scoreboard-зеркала;
- валидируемые intent-команды для будущих FTB Quests/KubeJS/Easy NPC связок.

Основной документ: [`threat_director/SPECIFICATION.md`](../threat_director/SPECIFICATION.md). Easy NPC представлен лишь неисполняемой sandbox-схемой; диалоги по требованию владельца не создавались.

## 5. Русская локализация

Paxi resource pack является единым слоем исправлений `ru_ru`. Авторские RU/EN-ключи имеют полный паритет, а тексты квестов написаны отдельно на каждом языке. Для сторонних модов overlay добавляет отсутствующие ключи и точечно заменяет ошибочные либо терминологически несовместимые переводы установленной версии.

Машинный отчёт: [`localization_baseline.json`](registries/generated/IF-M1-0001/localization_baseline.json). Релизный gate требует `total_missing_ru_keys = 0`; любое обновление JAR автоматически открывает gate заново.

Итог текущего среза: 0 отсутствующих ключей, 0 пустых значений, 0 символов замены UTF-8, 0 необъяснённых расхождений format-плейсхолдеров и 0 неизвестных overlay-ключей. Одно разрешённое исключение закреплено в [`localization_format_exceptions.json`](registries/localization_format_exceptions.json): Create намеренно показывает время по-русски в 24-часовом формате `%2$s:%3$s`, тогда как английский выбирает переданные тем же кодом 12-часовые аргументы и AM/PM. Сигнатура исключения закреплена, поэтому изменение upstream не пройдёт незаметно.

Статически закрыты и тексты вне `lang/*.json`: все **119/119** страниц встроенного руководства AE2 получили зеркальные `_ru_ru`-версии, прошли сверку frontmatter, GuideME/MDX-тегов, атрибутов, ссылок, якорей, resource ID и числовых значений; зарегистрированные смысловые исправления upstream использованы полностью. Словарь животных Alex’s Mobs проверен **91/91**, для 90 страниц поставляется редакторский overlay; две страницы и буквальные подписи demo-книги Citadel также переведены. Отчёты: [`guide_content_baseline.json`](registries/generated/IF-M1-0001/guide_content_baseline.json) и [`book_content_baseline.json`](registries/generated/IF-M1-0001/book_content_baseline.json).

`FULL_RU_GATE` всё ещё открыт только по честно зарегистрированной границе: GuideME `20.1.15` содержит три жёстко зашитых английских screen/accessibility title, которые resource pack изменить не может, а визуальную навигацию и переносы должен подтвердить владелец в игре. Подробности: [`RU_NON_LANG_CONTENT_BACKLOG.md`](RU_NON_LANG_CONTENT_BACKLOG.md).

- `lint_content.ps1` — JSON/SNBT-структура, ID, языковые ссылки, Paxi, теги, обязательные/запрещённые JAR, worldgen Create и синтаксис JavaScript.

- 51 активный JAR;
- 0 JAR с неизвестным CurseForge-происхождением;
- 0 недопустимых CurseForge CDN URL;
- 0 расхождений опубликованных source-хэшей: SHA-256 для direct exact-файлов и SHA-1/MD5 для записей CurseForge App;
- 0 отсутствующих обязательных зависимостей;
- 0 непроверенных обязательных диапазонов;

- 0 пустых/повреждённых переводов, необъяснённых расхождений плейсхолдеров и неизвестных overlay-ключей;

- 0 отсутствующих и 0 структурно дефектных страниц локализуемых книжных систем;

Эти числа пересобираются непосредственно перед передачей билда и не заменяют игровой тест.

## 7. Что намеренно не включено

- FTB Quests Optimizer `2.1.0` отклонён для текущей версии FTB Quests.
- Almost Unified удерживается до M2 и паспортов материалов.
- FTBQ Better Fluids удерживается до пользовательской проверки GTCEu/Create-тары.
- ProbeJS предназначен только для отдельного dev-клона.
- Place/Structure-задачи Quests Additions не входят в обязательный путь до узкого теста.
- Easy NPC preset и сюжетные диалоги не создаются до точной версии и безопасного экспортированного шаблона.
- Threat Director JAR не устанавливается до публикации точного CurseForge-файла; сейчас это документация, схемы и примеры.
- Боевые, фракционные, городские, биомные, пищевые, химические, атомные и космические волны не смешиваются с M1 smoke-билдом. Их версии проходят собственный exact-file gate перед установкой.
- Постоянный мир до worldgen-gate создавать нельзя.

Mekanism и Industrial Foregoing остаются запрещёнными архитектурными дублями GTCEu.

## 8. Следующий переход

Владелец выполняет [`BUILD_TEST_PROTOCOL.md`](BUILD_TEST_PROTOCOL.md) и возвращает `latest.log`, скриншоты квестов/JEI/Ponder и таблицу `OK/FAIL`. После успешного gate Build `IF-M1-0001` получает статус `ACCEPTED`, а работа переходит к M2: паспортам веществ, формам материалов, доменным контрактам, карте энергий и устранению обходов.
