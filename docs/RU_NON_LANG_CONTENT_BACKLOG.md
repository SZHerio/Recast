# Русификация текста вне `lang/*.json`

Дата среза: **2 августа 2026 года**  
Build ID: **`IF-M1-0001`**  
Статус: **`LANG_KEY_GATE=CLOSED`, `GUIDE_CONTENT_GATE=STATIC_CLOSED`, `BOOK_CONTENT_GATE=STATIC_CLOSED`, `FULL_RU_GATE=OPEN`**

## 0. Порядок работ: перевод сторонних модов идёт перед релизом

Решением владельца от 2 августа 2026 года перевод сторонних модов вынесен в **отдельную релизную волну** и не выполняется вместе с каждой волной установки.

Основание практическое: модлист ещё растёт целыми доменами, и ключи мода, который позже заменят или откатят, — потерянная работа. Поэтому счётчики отсутствующих русских ключей и непереведённых Markdown-страниц остаются **известным и допустимым долгом**, а не блокером приёмки промежуточного milestone.

Отсрочка не распространяется на:

- авторские строки `industrial_frontier` — они создаются сразу по-русски и всегда имеют паритет RU/EN;
- квесты, Ponder-сцены и справочные тексты сборки;
- измерение долга: `audit_instance.ps1` продолжает считать покрытие каждой волной, чтобы объём был виден.

`FULL_RU_GATE` остаётся релизным блокером: без него сборка не выпускается.

## 1. Зачем нужен отдельный gate

Сравнение `en_us.json` и `ru_ru.json` не охватывает книги, Markdown-руководства, Patchouli-страницы, внешние сценарные файлы и текст в data/resource pack. Поэтому число `0 missing language keys` не может само по себе означать «сборка полностью переведена».

`tools/audit_instance.ps1` создаёт три независимых отчёта:

- [`localization_baseline.json`](registries/generated/IF-M1-0001/localization_baseline.json) — языковые ключи, пустые строки, UTF-8, плейсхолдеры и overlay;
- [`guide_content_baseline.json`](registries/generated/IF-M1-0001/guide_content_baseline.json) — Markdown-страницы встроенных GuideME-руководств и наличие `_ru_ru`-версии.
- [`book_content_baseline.json`](registries/generated/IF-M1-0001/book_content_baseline.json) — локализуемые `.txt`-страницы книжных систем Citadel/Alex’s Mobs.

Финальный `FULL_RU_GATE` закрывается только тогда, когда закрыты все три отчёта, разобран ручной hardcoded-backlog и владелец визуально проверил тексты в игре.

Patchouli-книг и других Markdown/XML-корпусов пользовательской документации в текущих JAR не обнаружено. Этот вывод относится только к `IF-M1-0001`; каждый новый мод пересобирает отчёт.

GuideME ищет локализованную страницу по пути:

```text
assets/ae2/ae2guide/_ru_ru/<тот же относительный путь>.md
```

Если страницы нет, используется английский оригинал. Поэтому для M1 созданы все 119 зеркальных страниц; текущий машинный отчёт подтверждает `missing_ru_page_count = 0`, `qa_failure_count = 0` и `release_gate_met = true`.

Объём AE2-guide: около 300 тысяч знаков, 7,6 тысячи строк и 34,9 тысячи английских слов. Это отдельный редакторский корпус, а не набор нескольких подписей.

### Alex’s Mobs

Редакторский QA всего корпуса `91/91` завершён. В исходном `ru_ru` были исправлены терминологические и грамматические дефекты: неверное название Нижнего мира, расхождение Roadrunner с игровым `lang`, согласования и шаблонные формулировки. Для 90 страниц поставляется Paxi-overlay; страница `toucan.txt` оставлена штатной после сверки, поскольку правка ей не требуется.

### Citadel

Обе demo-страницы переведены через Paxi. Буквальные подписи из `root.json` и `link_example.json` также заменены русскими вариантами. Обычного survival-рецепта/лута demo-книги в JAR не найдено; статический gate закрыт, визуальное отображение при доступе к книге подтверждает владелец.

### Жёстко зашитые строки GuideME

В bytecode GuideME найдены три screen/accessibility title вне resource/lang-системы:

- `GuideME Guidebook`;
- `AE2 Guidebook Search`;
- `Navigation Tree`.

Они не исправляются resource pack. До финального релиза нужен узкий upstream-патч/mixin в собственном CurseForge-публикуемом моде либо подтверждённое исправление новой exact-версией GuideME. Это не основание добавлять общий runtime-переводчик.

На дату среза установлен `GuideME 20.1.15` (`CurseForge 1173950/8204776`) — актуальный релиз для Forge 1.20.1. Значит, безопасного обновления внутри той же платформы, которое можно было бы принять вместо патча, сейчас нет; три литерала остаются честно зарегистрированным upstream-backlog, а JAR не модифицируется локально.

## 3. Реализованное решение для AE2

AE2-guide переведён отдельным законченным корпусом **до открытия полноценной AE2-ветки игроку**, а не бессистемно по мере обнаружения английских страниц.

Выполнено:

1. Зафиксированы CurseForge-источник, опубликованный хэш и локальный SHA-256 исходного AE2 JAR.
2. Создано зеркальное дерево `_ru_ru/` для всех 119 страниц.
3. Сохранены YAML-frontmatter, относительные ссылки и GuideME-компоненты (`ItemLink`, `RecipeFor`, `GameScene`, `ImportStructure` и другие). Для ссылочных фрагментов добавлены стабильные `<a name="..." />` по [`guideme_required_anchors.json`](registries/guideme_required_anchors.json).
4. Текст отредактирован на естественном техническом русском без потери ограничений механик.
5. Термины синхронизированы с [`RU_STYLE_GUIDE.md`](RU_STYLE_GUIDE.md) и видимыми AE2-ключами Paxi-overlay.
6. Страницы поставляются через `IndustrialFrontier-Core` Paxi resource pack.
7. Паритет путей, frontmatter, MDX-теги и атрибуты, ссылки, якоря, resource ID, числа, UTF-8 и остатки исходного английского проверяются автоматически. Два подтверждённых смысловых исправления upstream закреплены в [`guideme_content_corrections.json`](registries/guideme_content_corrections.json), чтобы будущий audit отличал исправление от случайной потери числа.

Остаётся пользовательский пункт: владелец проверяет навигацию, поиск, сцены, переносы, кириллицу и переходы по предметам в игре.

Перевод не берётся из другой сборки и не копируется из стороннего квестбука. Допустимы только собственная редактура исходного руководства в рамках его лицензии и авторские пояснения сборки.

## 4. Release-gates корпуса

Для AE2 все статические требования ниже выполнены; последний визуальный пункт остаётся пользовательским:

- `default_markdown_page_count = translated_ru_page_count`;
- `missing_ru_page_count = 0`;
- каждый default-path имеет ровно один `_ru_ru` peer;
- ссылки не выходят в отсутствующие страницы;
- frontmatter и GuideME-теги разбираются;
- ни одна страница не остаётся пустой или формально переведённой заглушкой;
- термины совпадают с квестбуком;
- пользовательский визуальный тест пройден.

Для книжных `.txt`-корпусов дополнительно обязательны паритет путей, сохранность markup-токенов и редакторский QA существующего русского текста. Для hardcoded UI-строк ведётся отдельный ручной backlog: формальный page-count не может скрыть эти остатки.
