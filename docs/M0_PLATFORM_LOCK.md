# M0 — фиксация платформы Recast

Статус: **статически зафиксировано для Build `IF-M1-0001`; игровой gate ожидает проверки владельца**  
Дата: **2 августа 2026 года**

## 1. Неподвижная основа

- Minecraft `1.20.1`.
- Forge `47.4.22`.
- Базовая Java для пользовательского запуска: `17`, соответствующая Minecraft 1.20.1. Forge 47.4.x также может работать на Java 21, но этот вариант считается отдельным пользовательским compatibility-gate и обязательно записывается в отчёте.
- Технический namespace: `industrial_frontier`.
- Рабочее отображаемое название: **Recast**. Его можно заменить без миграции технических ID.
- Основной язык и обязательное полное покрытие: `ru_ru`.
- Английские исходники хранятся отдельно в `en_us`; они не являются шаблоном для буквального перевода.
- Codex не запускает Minecraft. Единственный источник результатов игрового теста — владелец сборки.

Основание для runtime-gate: представитель Forge подтверждает для ветки 47.4.x минимум Java 17 и совместимость с Java 21 в [официальном форуме Forge](https://forums.minecraftforge.net/topic/159435-4748-ignored-startup-flags/). Для воспроизводимости сборка сохраняет Java 17 базовой, пока владелец отдельно не подтвердит весь модлист на Java 21.

Namespace никогда не меняется из-за ребрендинга. Recipe ID, quest alias, Ponder ID, теги, datapack-пути и будущий Threat Director используют только `industrial_frontier`.

## 2. Политика происхождения модов

Владелец снял требование показывать каждое дополнение внутри CurseForge App. Новое правило:

1. Каждый сторонний JAR берётся только со страницы конкретного файла CurseForge или с соответствующего `edge.forgecdn.net` URL.
2. Для файла фиксируются project ID, file ID, точное имя, SHA-256 и назначение.
3. `minecraftinstance.json` — полезный источник метаданных уже установленных модов, но больше не является источником истины.
4. Ручное скачивание с GitHub Releases, Discord, Google Drive и неизвестных зеркал для релизного профиля запрещено.
5. Решением владельца от 2 августа 2026 года Codex может самостоятельно скачивать и устанавливать необходимые моды с CurseForge, не дожидаясь ручной установки владельцем. Правило источника при этом не смягчается: файл берётся только с `edge.forgecdn.net`, а его project ID, file ID, URL и локальный SHA-256 попадают в [`registries/curseforge_sources.json`](registries/curseforge_sources.json) в том же изменении. Список установленного всегда сообщается владельцу.
6. ~~Собственный Threat Director не попадает в `mods/`, пока его релизный JAR не опубликован на CurseForge.~~ **Правило отменено решением владельца от 3 августа 2026 года.** Оно было введено ради единообразия происхождения, но на практике блокировало собственный компонент сборки: Threat Director нельзя опубликовать на CurseForge раньше, чем он существует, а существовать он не мог из-за этого же правила. Теперь pack-native компонент может поставляться напрямую и регистрируется в реестре происхождения как авторский, а не сторонний файл. На сторонние моды правило CurseForge-only продолжает действовать без изменений.

Реестр прямых установок: [`registries/curseforge_sources.json`](registries/curseforge_sources.json). Полный снимок всех JAR генерируется `tools/audit_instance.ps1`.

## 4. Владение worldgen

Решение M0:

- **GTCEu — единственный владелец рудных месторождений и основной геологии прогрессии.**
- `removeVanillaOreGen=true` и `removeVanillaLargeOreVeins=true` остаются включены.
- Create worldgen отключается до отдельной паспортизации его природных ресурсов. Create остаётся производственным доменом, а не вторым генератором цинка.
- Целевой биомный профиль: **Biomes O' Plenty + TerraBlender**. Он добавляется отдельным пользовательским gate до создания первого производственного мира.
- YUNG's Better-* отвечает только за формы структур и не получает права владеть прогрессионным лутом.
- Immersive Petroleum в будущей волне владеет нефтяными залежами и первичной перегонкой; GTCEu — глубокой химией нефти.
- Одновременно включать GT-жилы, Immersive Geology и Large Ore Deposits без паспорта каждого месторождения запрещено.

В `saves/` на момент фиксации нет миров, поэтому изменение worldgen не мигрирует существующее прохождение. Создавать постоянный мир до пользовательского worldgen-gate нельзя.

## 5. Энергетическое соглашение

Сети не превращаются в один безликий RF-контур:

- Create SU — механическая передача, кинетические линии и логистика.
- GTCEu EU — точное напряжение, ток, кабели, трансформаторы и основная технологическая лестница.
- FE — муниципальная и внешняя инфраструктура отдельных модов.
- HBM-энергия — изолированный стратегический домен поздней игры.
- Пар и тепло — предпочтительные физические мосты между отраслями.

Для M0 сохраняется односторонний `nativeEUToFE=true` с соотношением `1 EU = 4 FE`, а двусторонние GT-конвертеры остаются выключены (`enableFEConverters=false`). Это позволяет питать ограниченную FE-инфраструктуру от промышленной сети, но не позволяет дешёвой FE-генерации обходить напряжения GTCEu. Любой будущий дополнительный конвертер должен иметь эпоху, потери, пропускную способность и объясняющий квест.

## 6. Зафиксированные владельцы данных

| Объект | Единственный владелец |
|---|---|
| Рецепты, теги, recipe removals | KubeJS |
| Авторский изменяемый лут | LootJS |
| Статические datapack/resource-pack ресурсы и RU overlay | Paxi |
| Квестовый граф и отображение обучения | FTB Quests |
| Эквивалентные item-tag условия | FTB Filter System |
| Состояние эпохи, репутации, принадлежности, договоров и операций | будущий Threat Director |
| Именные NPC и диалоговый интерфейс | будущий Easy NPC, только как представление состояния |
| Массовые вооружённые NPC | будущий TACZ: NPCs |

FTB Quests и Easy NPC не имеют права самостоятельно повышать эпоху или менять репутацию. Scoreboard будущего Threat Director — только read-only зеркало.

## 7. Зафиксированные ворота

- Almost Unified: **HOLD до M2**, пока нет паспортов материалов и узкого allow-list.
- FTBQ Better Fluids: **HOLD**, пока владелец не проверит GTCEu/Create-тару и командный прогресс.
- FTB Quests Optimizer `2.1.0`: **REJECT для текущего стека** — заявлена поддержка FTB Quests `2001.4.21`, а выбран `2001.4.22`; официальный changelog FTB также не рекомендует сторонний optimizer.
- ProbeJS: только dev-клон, не релизный профиль.
- Quests Additions: установлен как инструмент, но Place/Structure-задачи не входят в обязательный путь до узкого теста.
- Easy NPC: исполняемый preset не создаётся до установки точной версии и экспорта формата из GUI владельцем.
- Сюжетные диалоги на M0–M1 не пишутся; фиксируются лишь данные и интерфейсные контракты.

## 8. Выход из M0

Статически выполнено:

- платформа, namespace, worldgen-владелец и энергетическое соглашение закреплены;
- известные обязательные зависимости закрыты;
- все 51 активных JAR имеют CurseForge project/file ID, допустимый CDN URL, опубликованный upstream-хэш и локальный SHA-256 в воспроизводимом снимке;
- принят anti-grind стандарт;
- создан русский style guide, а language-key audit текущего 51-JAR среза доведён до `0` отсутствующих и дефектных ключей;
- non-lang корпуса закрыты статически: AE2 GuideME `119/119`, Alex’s Mobs `91/91` с 90 редакторскими Paxi-overrides, Citadel `2/2`; глобальный `FULL_RU_GATE` открыт только из-за трёх hardcoded-заголовков GuideME и визуального QA владельца;
- постоянных миров ещё нет.

M0 acceptance не может быть закрыт без владельца:

- реальная загрузка Forge без ошибок;
- генерация пробного мира и отсутствие нежелательной руды Create;
- отображение русской книги, Ponder-сцены и JEI-рецептов;
- совместимость всех новых authoring-модов в одном процессе.

После карточки `IF-M1-0001` статус M0 меняется с `STATIC_COMPLETE / USER_GATE_PENDING` на `ACCEPTED` либо возвращается на исправление.
