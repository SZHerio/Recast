# Список модов к установке — этап M8.5

Дата составления: **4 августа 2026 года**
Обоснование выбора: [`CONTENT_AND_MACHINERY_PLAN.md`](CONTENT_AND_MACHINERY_PLAN.md)

Моды скачивает и устанавливает владелец, как во всех предыдущих волнах. Codex
файлы не качает.

Версии в колонке «проверенная сборка» — те, что работают в HardTech на
Minecraft 1.20.1 / Forge. Это не требование, а подсказка: если на CurseForge
лежит более свежий файл для 1.20.1, берите его.

**После установки** нужно вернуть Codex список фактических имён файлов — он
заносит каждый в реестр происхождения с project/file ID и SHA-256 и запускает
аудит. Мод без записи в реестре считается неизвестным источником и роняет
проверку.

## Волна 1 — структуры мира

Приоритет первый. Без них модулю фракций не из чего строить базы, а мир
остаётся пустым.

| Мод | Проверенная сборка | Что даёт |
|---|---|---|
| Repurposed Structures | `repurposed_structures-7.1.21+1.20.1-forge` | 156 структур, 3085 шаблонов — варианты ванильных построек во всех биомах |
| Towns and Towers | `Towns-and-Towers-1.12-Fabric+Forge` | 63 структуры, 816 шаблонов — деревни и городки под биомы |
| Moog's Voyager Structures | `mvs-4.1.5-1.20` | 128 структур на поверхности |
| Philip's Ruins | `PhilipsRuins1.20.1-5.7` | 29 структур, 300 шаблонов — руины как след прошлого |
| Moog's End Structures | `mes-1.4.6-1.20` | 24 структуры в Крае |

**Зависимости:** Yung's API (`YungsApi-1.20-Forge-4.0.6`) — требуется частью
структурных модов.

**Проверка перед приёмкой.** У каждого мода читаются таблицы лута: правило
`prohibited_leaks` запрещает выдачу готового изделия будущей эпохи, и оно
действует на чужие структуры так же, как на свои. Всё, что нарушает, гасится
датапаком до создания мира.

## Волна 3 — второй приоритет

Ставится после того, как первые две прошли пользовательскую проверку.

| Мод | Проверенная сборка | Что даёт |
|---|---|---|
| ExtendedAE | `ExtendedAE-1.20-1.4.12-forge` | Глубина для AE2 после P5 |
| AdvancedAE | `AdvancedAE-1.3.3-1.20.1` | То же, другой набор |
| MEGA Cells | `megacells-forge-2.4.6-1.20.1` | Ёмкости большого объёма |
| ME Requester | `merequester-forge-1.20.1-1.1.5` | Автозаказ по остатку |
| Functional Storage | `functionalstorage-1.20.1-1.2.10` | Хранение до появления ME-сети |
| Ender Tanks | `endertanks-forge-1.20.1-1.5` | Жидкости на расстоянии |
| Programmed Circuit Card | `Programmed Circuit Card-1.20.1-1.2.9` | Убирает возню с конфигурационной схемой GregTech |
| CP Tools | `CPTools-1.8.0+1.20.1-forge` | То же для остальной рутины GregTech |
| Terralith | `Terralith_1.20.x_v2.5.4` | Рельеф и биомы; руду не трогает |
| Tectonic | `tectonic-3.0.17-forge-1.20.1` | Горы, реки и пещеры |
| Yung's Cave Biomes | `YungsCaveBiomes-1.20.1-Forge-2.0.5` | Пещеры перестают быть одинаковыми |
| Elevator | `elevatorid-1.20.1-1.9.1-forge` | Вертикальное перемещение без лестниц |
| Traveler's Backpack | `travelersbackpack-forge-1.20.1-9.1.46` | Рюкзак; на прогрессию не влияет |

**Зависимость:** TerraBlender (`TerraBlender-forge-1.20.1-3.0.1.10`) —
требуется Terralith.

**Осторожно с worldgen.** Terralith, Tectonic и Yung's Cave Biomes меняют
рельеф и биомы. Правило сборки «рудной генерацией владеет GregTech» они не
нарушают, но после установки нужен **новый мир**: на существующем появится
граница между старыми и новыми чанками.

## Чего в списке нет

- **Ad Astra** — удалён решением владельца в M7, возврата нет.
- **Магия** — Botania, Blood Magic, Malum: правило сборки о главном пути.
- **Avaritia, Extended Crafting, All The Compressed** — сжатие ради сжатия,
  против правила о гринде.
- **Моды `next_*`** — закрытые серверные, не распространяются.
- **Cobblemon и окружение** — другой жанр.
