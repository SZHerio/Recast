# Архив этапов разработки

Здесь лежат отчёты, протоколы проверки и передачи по этапам M0–M11 — тем
волнам работ, из которых собиралась сборка. Двадцать семь документов перенесены
сюда 10 августа 2026 года при подготовке полной версии.

**Почему они больше не в основной папке.** Готовая сборка описывается тем, что
в ней есть, а не тем, в каком порядке это делалось. Игроку и человеку, который
возьмётся её продолжать, нужны замысел, правила и известные проблемы — а не
хроника девяти волн.

**Почему они не удалены.** В них записаны причины решений: почему выбран один
мод, а не другой, почему домен устроен так, откуда взялось ограничение. Такие
объяснения нигде больше не повторяются, и терять их нельзя.

Ссылки из живых документов на эти файлы остаются рабочими — путь изменился
только на один каталог.
