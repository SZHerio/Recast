## Принятые решения

- **AE2 не трогаем.** Уже заперт за P5 тремя скриптами; его ручные рецепты —
  часть внутренней логики мода.
- **Валюта остаётся** пилотом городской экономики. Монеты ручные, оборудование
  машинное. Настоящий риск — ассортимент торговых автоматов, а не крафт.
- **Refurbished Furniture и Framework сняты** в `disabled_mods/design_rejected/`:
  вторая техносистема рядом с GregTech и Create.
- **Инструменты ручные, броня машинная.** Кирка ломается в шахте — возвращаться
  за ней к сборщику нельзя. Броню делают партией заранее.
- **P3 и жар делать не нужно:** проверка по 65 922 рецептам показала ноль ручных
  дублей — GregTech закрыл их своими настройками.

## Пять отключённых машин: где именно стоит работа

Файлы: `kubejs/startup_scripts/00_core_registry/m85_*.js.disabled`.

Ошибка `missing pattern while creating multiblock` возникает внутри
`MultiblockMachineBuilder.register`. Проверено и **опровергнуто**: дело не в
разбиении цепочки вызовов — обе формы дают одну ошибку.

Эталон найден: `Instances/HardTech/kubejs/startup_scripts/machines/greenhouse.js`.
Событие, порядок вызовов, `FactoryBlockPattern`, `aisle`, `where`, `build` — всё
совпадает с нашим кодом. Взят только способ вызова, содержимое не копируется.

**Гипотеза для следующей проверки.** У эталона файл машины содержит один блок
регистрации, а тип рецепта объявлен отдельно. У нас в одном файле два блока
подряд: сначала `gtceu:recipe_type`, следом машина, которая на него ссылается.
Возможно, GregTech требует готовности типа рецепта раньше создания машины.
Проверка: разнести на два файла так, чтобы тип регистрировался заведомо раньше
(например, `00_recipe_types.js` и `85_water_treatment.js`), включить одну
машину и запустить игру.

- пять машин по гипотезе выше;

  вместо 673 и 133 JAR вместо фактических.

## Рабочие инструменты, появившиеся сегодня

- `tools/audit_hand_recipes.py` — сплошной обход всех рецептов всех модов;
- `tools/audit_recipe_owners.py` — лестница выхода, поиск сломанных ступеней;
- `tools/validate_recipe_devolution.py` — страж линии передачи рецептов;
- `kubejs/server_scripts/99_export/11_recipe_index.js` — выгрузка всех рецептов
  из запущенной игры в `kubejs/exported/recipe_index.json`; лежит последней в
  очереди, поэтому отражает итоговое состояние.
