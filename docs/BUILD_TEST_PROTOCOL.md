# Карточка пользовательского теста

> Эта карточка сохраняет исходный smoke-test `IF-M1-0001`. Для текущего M2 поверх неё выполните отдельный [`M2_BUILD_TEST_PROTOCOL.md`](history/M2_BUILD_TEST_PROTOCOL.md); M2 не отменяет проверки загрузки и русификации M1.

## Build ID: IF-M1-0001

Затронуто: загрузка Forge, JEI, KubeJS, Create-интеграция, FTB Quests, FTB Teams, FTB Filter System, Paxi, PonderJS, LootJS, AE2/GuideME и встроенные книжные тексты.  
Нужен новый мир: **для smoke-теста — новый временный мир; постоянный мир пока не создавать**.

Граница карточки: проверяется русский авторский M1-слой и визуальное применение статически завершённых non-lang корпусов. AE2 GuideME имеет `119/119` русских страниц; известными допустимыми остатками остаются только три hardcoded-заголовка самого GuideME, перечисленные в [`RU_NON_LANG_CONTENT_BACKLOG.md`](RU_NON_LANG_CONTENT_BACKLOG.md).

### Перед запуском

1. Убедитесь, что профиль использует Minecraft `1.20.1`, Forge `47.4.22` и базовую Java `17`. Если осознанно тестируете на Java `21`, не меняйте её ради карточки, но укажите точную версию в результате.
2. Не возвращайте старый JEI из `backups/` одновременно с новым.
3. Для первого теста не добавляйте другие моды: иначе лог перестанет изолировать M1.

### Проверить

1. Игра доходит до главного меню без окна отсутствующих зависимостей.
2. Создаётся новый временный мир; вход не завершается ошибкой datapack.
3. В списке datapack виден `IndustrialFrontier-Data`, а русский resource pack применён Paxi.
4. Открывается FTB Quests; видны группы «Вводный курс» и «Помощь и восстановление».
5. Весь текст этих глав отображается по-русски, без `{industrial_frontier...}` вместо строк.
6. Первый квест автоматически замечает Overworld; checkmark-задания нажимаются.
7. Задание с тегом принимает любые восемь обычных брёвен.
8. JEI показывает рецепт четырёх сундуков из восьми брёвен с ID `industrial_frontier:bulk_chest_from_logs`.
9. Крафт выдаёт ровно четыре сундука и задание их замечает, не поглощая предметы.
10. JEI показывает Create-mixing рецепт блока глины из четырёх комков глины.
11. Для `create:basin` доступна Ponder-сцена «Партия, буфер и узкое место»; блоки и русский текст видны.
12. Открывается встроенное руководство AE2; корень, разделы «Механики AE2», «Предметы, блоки и машины» и «Примеры схем» отображаются по-русски.
13. В AE2 GuideME работают русский поиск, переходы по предметам и внутренние ссылки. Проверяются минимум страницы автоматического изготовления, каналов, кабелей, процессора изготовления, P2P-туннелей, пространственного ввода-вывода и кабельного анкера.
14. На проверенных GuideME-страницах нет английских абзацев, сломанной MDX-разметки, пустых сцен, повреждённой кириллицы или ссылок в отсутствующую страницу. Три hardcoded-заголовка из backlog не считать новым дефектом.
15. Словарь животных Alex’s Mobs при доступе отображает естественный русский текст; отдельно проверить любую исправленную страницу и тукана. Demo-книгу Citadel проверить только если она доступна без вмешательства в прогрессию.
16. В `latest.log` нет `ERROR`/stacktrace от `industrial_frontier`, KubeJS, PonderJS, LootJS, Paxi, FTB Quests/Teams/Library/Filter System, AE2, GuideME, Alex’s Mobs, Citadel или JEI.
17. В пробном мире не встречается руда, добавленная worldgen Create; GT-жилы генерируются. Достаточно короткой творческой проверки, полноценное прохождение не нужно.

### Ожидаемый результат

- один связный русский вводный квестбук;
- два безопасных материально эквивалентных рецепта;
- рабочая Ponder-сцена;
- русское руководство AE2 и русские встроенные книжные тексты без структурных дефектов;
- никаких missing-dependency и script errors;
- прогресс команды сохраняется после перезахода.

### Вернуть Codex

- `logs/latest.log` целиком;
- скриншот обеих квестовых групп;
- скриншот JEI-рецепта сундуков;
- скриншот или короткое описание Ponder-сцены;
- скриншоты корня GuideME и по одной странице из механик, предметов и примеров;
- результат пунктов `1–17` в виде `OK/FAIL`;
- шаги воспроизведения каждой проблемы;
- одиночная или сетевая игра.
- точная версия Java из начала `latest.log`.

До получения этих материалов M0–M1 считаются статически собранными, но не принятыми.
