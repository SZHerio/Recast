# M10 — отчёт о внедрении

Build ID: `IF-M10-0001`  
Дата: 8 августа 2026 года  
Статус: `STATIC_IMPLEMENTED / RELEASE_GATES_OPEN`

Первоначальный срез M10 был собран без переводов; последующая локализационная
волна слита и статически принята в тот же рабочий build. Minecraft, Forge,
клиент, сервер и миры при этой работе не запускались.

Это не релиз-кандидат. Текущий построчный счёт: 14 пунктов — 6 `DONE`, 5
`OWNER`, 2 `PARTIAL`, 0 `NOT_DONE`, 1 `DEFERRED`. По правилам отчётности
наличие `PARTIAL` означает, что M10 не закрыт.

## 1. Что появилось

### Статический аудит темпа и прогрессии

`tools/audit_progression.py` переписан под текущие поля grind-реестра и теперь
проверяет не только числа цепочек, но и P0–P9, ссылки между реестрами,
достижимость веществ, циклы, скачки эпох и физические evidence. Канонический
JSON хранит SHA-256 входов: если любой из трёх реестров изменится, M10-validator
потребует пересобрать отчёт.

Результат текущего среза:

| Метрика | Результат |
|---|---:|
| Узлы P0–P9 | 10/10 |
| Последовательные переходы | 9/9 |
| Grind-цепочки / компоненты | 21 / 21 |
| `GREEN` / `EXPLAIN` | 13 / 8 |
| Green / explain метрики | 50 / 13 из 63 |
| Hard-превышения | 0 |
| Проверенные evidence-пути | 69/69 |
| Необъяснённые блокеры | 0 |
| Объяснённые предупреждения | 68 |

Исправлена доказуемо устаревшая карточка городских рационов: Farmer's Delight
и Create Central Kitchen установлены, поэтому budget-chain теперь
`ACTIVE_M2/EXPLAIN`, а не `GATED_NOT_INSTALLED`. Шесть ручных операций и шесть
переносов не уменьшались без измерения. Сам runtime-компонент остаётся gated до
реализации двух типизированных входов: питьевой воды и городского demand.

### Релизная комплектация

Созданы четыре профиля:

- `dev` — полная приватная рабочая среда авторинга;
- `owner-test` — чистый instance для ручной приёмки;
- `release` — только утверждённое runtime-содержимое;
- `curseforge-export` — `manifest.json` плюс `overrides/`.

Машиночитаемый allowlist запрещает сторонние JAR, миры, backup, логи,
crash-report, скриншоты, launcher-state, пользовательские карты и кэши. Пока
gate открыт, staging ZIP намеренно не создан: готовый архив выглядел бы как
релиз-кандидат, хотя source-policy и runtime ещё не прошли.

### Лицензии и миграция

Новый статический inventory читает метаданные и SHA-256 всех 133 JAR, не
загружая классы модов. У всех найдено license declaration; неизвестных файлов
нет. Три декларации требуют ручного уточнения перед любой прямой поставкой JAR:
Applied Energistics 2 и GuideME отсылают к репозиторию без точного имени
лицензии, Create Deco содержит placeholder `Insert License Here`. В текущем
CurseForge-профиле они остаются только manifest-ссылками и в архив не входят.

`THIRD_PARTY_NOTICES.md` запрещает прямую перепаковку JAR по умолчанию и
разделяет manifest-доставку, direct redistribution и чужие assets. Миграционный
документ требует отдельный новый instance, полный backup, проверку копии мира,
сохранение stable IDs и откат целым архивом, а не частичным набором region.

### Квестбук как учебник

Статическая редакторская проверка охватила 24 главы и 214 квестов:

- 0 отсутствующих `purpose` и grind-class;
- 0 дубликатов alias и engine ID;
- 214 description-блоков и 214 task-блоков;
- 653 ссылки на объясняющие абзацы;
- обязательная лестница P0–P9 — 10 глав и 118 mainline-квестов.

Структурный и локализационный PASS получены. Полная вычитка остаётся `PARTIAL`
до непрерывного прохождения игроком без внешней wiki. Отдельно зафиксирован
риск пяти отключённых авторских машин: книга не должна обещать собственный
механизм, которого в runtime нет.

### Единый owner-test

`M10_BUILD_TEST_PROTOCOL.md` и журнал объединяют разрозненные проверки в один
воспроизводимый gate:

- честный тайминг P0–P9 и журнал раздражения I0–I4;
- первый час, фабрика, город, космос, рейд и NPC 20/40/80 с FPS/TPS/MSPT;
- командные квесты, join/leave/relog и изоляция team-state;
- единственный `industrial_frontier:tech_epoch`, репутация и Threat Director;
- TaCZ ammo/reload, TACZ: NPCs, Easy NPC, CBC damage-budget;
- warning → negotiation → active/recovery → cooldown → closed;
- визуальный регресс M9 на разных разрешениях и GUI scale.

Для каждого блока заданы числовой PASS/FAIL, обязательные логи/скриншоты и
правило тестировать разрушительные сценарии только на копии мира.

## 2. Что намеренно не делалось

- Minecraft/Forge не запускались и результат runtime не выдумывался.
- Сторонние JAR не скачивались и не заменялись.
- CC:Tweaked/Advanced Peripherals не понижались вслепую: совместимую
  CurseForge-only пару нужно выбрать и затем проверить запуском владельца.
- Публичный ZIP не создавался до закрытия его gate.
- Полноценные сюжетные диалоги не создавались: это ранее отложенная владельцем
  задумка, поэтому их редакторская проверка имеет `DEFERRED`.

## 3. Открытые release-blocker

### 1. Источник CC:Tweaked

Установленная версия CC:Tweaked 1.120.0 отсутствует на CurseForge. Она известна
и хэш совпадает, но это не делает её совместимой с правилом владельца «версии
только с CurseForge». Требуется выбрать совместимую CurseForge-only пару
CC:Tweaked/Advanced Peripherals и провести owner runtime test либо явно изменить
политику распространения. Текущий public profile остаётся `NOT_READY`.

### 2. Русская локализация

Поток принят со статусом `DONE`: словари, руководства, Patchouli-книги и
CraftOS-перекрытия прошли повторный структурный, форматный и остаточный
языковой аудит. Игровая отрисовка остаётся частью owner runtime test.

### 3. Runtime и multiplayer

Нет фактических результатов полного прохождения, performance, multiplayer,
боевого регресса и визуального M9. Их может закрыть только владелец по готовому
протоколу.

### 4. Финальная редактура книги

Структура и локализация подтверждены статически, но непрерывность терминологии
и понятность без внешней wiki ещё должны быть подтверждены пользовательским
журналом.
