# Шарики материи

<ItemImage id="matter_ball" scale="4" />

Шарик универсальной материи служит боеприпасом для <ItemLink id="matter_cannon" /> и ингредиентом для
[шариков с краской](paintballs.md).

Один шарик получается из 256 предметов или вёдер, переработанных в <ItemLink id="condenser" /> в режиме производства шариков материи.
