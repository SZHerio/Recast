# Опустошение и заполнение ячеек

Как быстро выгрузить содержимое ячейки в сундук, систему ящиков или рюкзак либо, наоборот, заполнить ячейку из такого
хранилища?

Для этого используйте <ItemLink id="io_port" /> и подсеть, ограничивающую места, куда порт может помещать ресурсы и
откуда может их забирать.

## Настройки

* Центральная кнопка со стрелкой в интерфейсе <ItemLink id="io_port" /> (1) выбирает режим «Передать данные в сеть» или
  «Передать данные в ячейку хранения». Для максимальной скорости установлены три Карты ускорения.
* <ItemLink id="storage_bus" /> (2) использует стандартные настройки.

## Принцип работы

### Режим «Передать данные в сеть»

1. <ItemLink id="io_port" /> пытается выгрузить содержимое установленной
   [ячейки хранения](../items-blocks-machines/storage_cells.md) в
   [сетевое хранилище](../ae2-mechanics/import-export-storage.md).
2. Единственное хранилище подсети — <ItemLink id="storage_bus" />. Оно помещает предметы, жидкости и другие ресурсы в
   любое хранилище, расположенное перед шиной.
* <ItemLink id="energy_cell" /> создаёт достаточно большой буфер [энергии](../ae2-mechanics/energy.md), чтобы сеть не
  обесточилась из-за переноса множества предметов за один игровой такт.

### Режим «Передать данные в ячейку хранения»

1. <ItemLink id="io_port" /> пытается выгрузить содержимое
   [сетевого хранилища](../ae2-mechanics/import-export-storage.md) в установленную
   [ячейку хранения](../items-blocks-machines/storage_cells.md).
2. Единственное хранилище подсети — <ItemLink id="storage_bus" />. Оно извлекает предметы, жидкости и другие ресурсы из
   любого хранилища, расположенного перед шиной.
* <ItemLink id="energy_cell" /> создаёт достаточно большой буфер [энергии](../ae2-mechanics/energy.md), чтобы сеть не
  обесточилась из-за переноса множества предметов за один игровой такт.
