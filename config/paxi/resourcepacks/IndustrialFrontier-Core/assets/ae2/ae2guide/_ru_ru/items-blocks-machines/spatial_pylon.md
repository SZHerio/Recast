# Пространственный пилон

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

Пространственные пилоны создают поле для [пространственного ввода-вывода](../ae2-mechanics/spatial-io.md) и задают границы
области, на которую подействует перенос.

Каждая непрерывная линия пилонов занимает 1 [канал](../ae2-mechanics/channels.md).

Для работы линия должна состоять как минимум из 2 блоков.
