# Кабельный анкер

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы, которые крепятся к кабелю. Они позволяют разъединять соседние кабели, сооружать из кабелей
лестницы или создавать впечатление, что кабель закреплён на окружающих стенах. Анкеры также нужны для изготовления
<ItemLink id="facade" />.

Кабельный анкер не даёт кабелю образовать соединение с той стороны, на которой установлен.

По анкерам можно подниматься как по лестнице.
