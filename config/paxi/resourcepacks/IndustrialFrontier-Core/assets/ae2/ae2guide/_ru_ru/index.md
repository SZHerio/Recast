# Что такое Applied Energistics 2?

# Как пользоваться этим руководством

* Откройте боковую панель слева, чтобы увидеть содержание.
* На многих страницах есть интерактивные сцены. Если рядом со сценой расположены кнопки ![Плюс](assets/diagrams/plus.png)
и ![Минус](assets/diagrams/minus.png) для изменения масштаба, камеру можно вращать и перемещать.
Зажмите левую кнопку мыши и ведите мышь, чтобы вращать камеру; используйте правую кнопку, чтобы перемещать её.

# Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механики для логистики и хранения. Огромную комнату с сундуками можно
заменить компактной МЭ-сетью, но это лишь начало.
Applied Energistics рассчитан на совместную работу с другими модами сборки и позволяет автоматизировать их процессы.
Систему можно настроить так, чтобы одним щелчком изготовить все промежуточные компоненты сложной производственной
цепочки и её конечный результат, поддерживать заданный запас предметов либо просто перемещать предметы по базе.
