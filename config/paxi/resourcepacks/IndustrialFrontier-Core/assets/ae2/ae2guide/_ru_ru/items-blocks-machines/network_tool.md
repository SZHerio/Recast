# Сетевой инструмент

<ItemImage id="network_tool" scale="4" />

Сетевой инструмент — модифицированный [гаечный ключ](wrench.md), который показывает диагностические сведения о сети
и хранит [карты улучшений](upgrade_cards.md). Как и обычный ключ, он быстро разбирает блоки и снимает
[кабельные части](../ae2-mechanics/cable-subparts.md), но не умеет поворачивать блоки.

В инструменте есть 9 слотов для [карт улучшений](upgrade_cards.md). Пока он находится в вашем инвентаре, эти карты
доступны из интерфейса любого устройства AE2.

Щелчок правой кнопкой мыши по любой части сети открывает окно диагностики, похожее на окно <ItemLink id="controller" />.
В нём отображаются:

*   количество занятых каналов сети;
*   переключатель глобального отображения энергии в AE или E/FE;
*   текущий запас [энергии](../ae2-mechanics/energy.md) в сети и её максимальная ёмкость;
*   входная и потребляемая мощность сети;
*   список всех [устройств](../ae2-mechanics/devices.md) и компонентов сети.

Это окно также помогает проверить, принадлежат ли два кабеля или устройства одной сети, когда вы настраиваете
[подсети](../ae2-mechanics/subnetworks.md).

## Скрытие фасадов

<a href="facades.md">Фасады</a> скрываются, пока сетевой инструмент находится в любой руке.

С блоками за скрытыми фасадами можно взаимодействовать, не снимая сами фасады.
