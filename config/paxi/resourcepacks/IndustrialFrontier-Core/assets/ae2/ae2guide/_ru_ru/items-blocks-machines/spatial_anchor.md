# Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Чтобы [устройства](../ae2-mechanics/devices.md) МЭ-сети работали, содержащие их чанки должны оставаться загруженными. Если загружена лишь часть сети,
она может работать неправильно. Пространственный якорь принудительно загружает все чанки, занятые его сетью.
Даже одного кабеля, пересекающего границу чанка, достаточно, чтобы якорь загрузил новый чанк.

Загрузка распространяется через [квантовые мосты](quantum_bridge.md), но не между измерениями. Поэтому для квантового моста в Нижний мир
нужен пространственный якорь и в сети вашей базы, и в сети на стороне Нижнего мира.

По умолчанию якорь также включает случайные такты в загруженных чанках. Это поведение можно отключить в конфигурации AE2.

При желании блок можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Настройки

*   Пространственный якорь открывает глобальную настройку отображения энергии в AE или E/FE.
*   Голограмма в мире может показывать загружаемые чанки.

## Энергопотребление

Пространственный якорь расходует [энергию](../ae2-mechanics/energy.md) по формуле:

e = 80 + (x\*(x+1))/2

где x — число загружаемых чанков.
