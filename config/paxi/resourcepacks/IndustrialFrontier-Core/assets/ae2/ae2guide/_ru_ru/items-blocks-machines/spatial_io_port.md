# Порт пространственного ввода-вывода

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

Порт участвует в [пространственном вводе-выводе](../ae2-mechanics/spatial-io.md): он удерживает [пространственную ячейку](spatial_cells.md)
и управляет операцией переноса пространства.

Для автоматизации ячейку можно вставлять и извлекать любой предметной логистикой, например воронками или шинами AE2.
