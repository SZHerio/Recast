# Флюисовый кристалл

<ItemImage id="fluix_crystal" scale="4" />

*«Флюисовые кристаллы обладают уникальной способностью поглощать энергию и преобразовывать её из одной формы в другую. На них основана вся материально-энергетическая технология».*

Это один из основных ингредиентов блоков, [устройств](../ae2-mechanics/devices.md) и предметов AE2. Для получения бросьте в воду кварц Нижнего мира, красную пыль и <ItemLink id="charged_certus_quartz_crystal" />.

Процесс можно [автоматизировать](../example-setups/throw-in-water-automation.md) с помощью <ItemLink id="formation_plane" /> и <ItemLink id="annihilation_plane" />.
