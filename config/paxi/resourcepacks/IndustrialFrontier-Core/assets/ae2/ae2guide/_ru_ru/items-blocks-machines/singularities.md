# Сингулярность

<ItemImage id="singularity" scale="4" />

Чрезвычайно плотный шар материи.

Создаётся из 256 000 предметов или вёдер жидкости в <ItemLink id="condenser" />, работающем в режиме сингулярности.

## Сингулярность квантовой запутанности

<ItemImage id="quantum_entangled_singularity" scale="4" />

Сингулярности квантовой запутанности нужны для соединения двух [квантовых сетевых мостов](quantum_bridge.md) и всегда возникают согласованными
парами. Поместите 1 сингулярность из пары в <ItemLink id="quantum_link" /> моста с каждой стороны, чтобы установить связь.

Для их получения вызовите реакцию между <ItemLink id="minecraft:ender_pearl" /> или <ItemLink id="ender_dust" />\
и <ItemLink id="singularity" />. Реакцию запускает практически любой взрыв.

<RecipeFor id="quantum_entangled_singularity" />

***Подойдёт почти любой взрыв — даже взрыв крипера.***

Результатом всегда будет пара, хотя для реакции нужна только одна <ItemLink id="singularity" />.

Созданную пару полезно сразу подписать на обычной наковальне, чтобы не перепутать связанные сингулярности.
