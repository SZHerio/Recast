# Шина хранения

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/storage_bus.snbt" />
</GameScene>

Хотите сохранить нагромождение сундуков вместо перехода на более удобное хранилище? Подключите шину хранения.

Шина превращает соприкасающийся с ней инвентарь в [хранилище сети](../ae2-mechanics/import-export-storage.md).
МЭ-сеть видит содержимое этого инвентаря и может помещать туда или извлекать оттуда ресурсы, когда другие
[устройства](../ae2-mechanics/devices.md) обращаются к сетевому хранилищу.

В AE2 механики возникают из взаимодействия разных [устройств](../ae2-mechanics/devices.md), поэтому шину хранения необязательно
использовать только для хранения. Если в [подсети](../ae2-mechanics/subnetworks.md) сделать одну или несколько шин хранения единственным доступным хранилищем,
они превратятся в источник или приёмник для передачи предметов. Пример приведён в схеме [«Подсеть-труба»](../example-setups/pipe-subnet.md).

Шины относятся к [кабельным частям](../ae2-mechanics/cable-subparts.md).

## Фильтрация

По умолчанию шина принимает всё. Предметы в слотах фильтра образуют белый список: хранить разрешается
только указанные предметы.

Предметы и жидкости можно перетаскивать в слоты из JEI, даже если их нет в инвентаре.

Щёлкните ПКМ контейнером с жидкостью, например ведром или баком, чтобы добавить в фильтр саму жидкость, а не предмет-контейнер.

## Приоритет

Приоритет настраивается кнопкой с гаечным ключом в правом верхнем углу интерфейса.
Поступающий в сеть предмет сначала направляется в хранилище с наибольшим приоритетом. Если два хранилища имеют одинаковый приоритет,
предпочтение получает то, где такой предмет уже есть. Отфильтрованное хранилище в своей группе приоритета считается уже содержащим указанный предмет.
При извлечении ресурсов сеть начинает с хранилища с наименьшим приоритетом. Поэтому при обычной работе хранилища с высоким приоритетом
заполняются, а с низким — опустошаются.

## Настройки

*   Фильтр шины можно автоматически заполнить текущим содержимым соседнего инвентаря.
*   Можно разрешить или запретить сети видеть предметы, которые шина не способна извлечь из соседнего инвентаря.
    Например, шина хранения не может достать предмет из среднего входного слота <ItemLink id="inscriber" />.
*   Фильтр может действовать и при помещении, и при извлечении либо только при помещении.
*   Шина может работать в обе стороны, только помещать предметы или только извлекать их.

## Улучшения

Шина хранения поддерживает следующие [улучшения](upgrade_cards.md):

*   <ItemLink id="capacity_card" /> — увеличивает число слотов фильтра.
*   <ItemLink id="fuzzy_card" /> — позволяет учитывать степень повреждения предмета и/или игнорировать его NBT.
*   <ItemLink id="inverter_card" /> — превращает белый список фильтра в чёрный.
*   <ItemLink id="void_card" /> — уничтожает поступающие предметы, если соседний инвентарь заполнен, и не даёт фермам остановиться из-за переполнения. Обязательно настройте фильтр, чтобы не потерять нужные ресурсы.
