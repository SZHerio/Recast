# Верстак для ячеек

<BlockImage id="cell_workbench" scale="8" />

Верстак для ячеек позволяет настраивать [ячейки хранения](storage_cells.md) и предметы
<ItemLink id="view_cell" />.

В ячейку можно устанавливать [карты улучшений](upgrade_cards.md) и задавать раздел — фильтр ресурсов, которые она будет
принимать.

Предметы и жидкости можно перетаскивать в ячейки фильтра из JEI, даже если у вас нет соответствующего ресурса.

Щёлкните правой кнопкой мыши с контейнером жидкости, например ведром или резервуаром, чтобы добавить в фильтр саму
жидкость, а не предмет-контейнер.

## Настройки

В левом верхнем углу интерфейса верстака находятся несколько кнопок:

*   создать раздел ячейки на основе её текущего содержимого;
*   очистить раздел ячейки;
*   сохранять настройки раздела после извлечения ячейки, чтобы копировать их между ячейками.
