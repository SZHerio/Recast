# МЭ-накопитель

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

МЭ-накопитель — [устройство](../ae2-mechanics/devices.md), в которое устанавливаются [ячейки хранения](storage_cells.md)
для подключения к [сетевому хранилищу](../ae2-mechanics/import-export-storage.md). В каждом из 10 слотов помещается одна ячейка.

При необходимости ячейки можно помещать в накопитель и извлекать из него любой предметной логистикой: например, воронками
или МЭ-шинами.

Блок можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

## Индикаторы состояния ячеек

Светодиод на каждой ячейке в накопителе показывает её состояние:

| Цвет      | Состояние                                                                                       |
| :-------- | :---------------------------------------------------------------------------------------------- |
| Зелёный   | Ячейка пуста                                                                                     |
| Синий     | В ячейке есть содержимое                                                                         |
| Оранжевый | Исчерпан лимит [типов](../ae2-mechanics/bytes-and-types.md); новые типы добавить нельзя          |
| Красный   | Исчерпан лимит [байтов](../ae2-mechanics/bytes-and-types.md); новые предметы поместить нельзя    |
| Чёрный    | Нет энергии либо у накопителя нет [канала](../ae2-mechanics/channels.md)                          |

## Приоритет

Чтобы задать приоритет, нажмите значок гаечного ключа в правом верхнем углу интерфейса. Предмет, поступающий в сеть,
сначала направляется в хранилище с наибольшим приоритетом. Если два хранилища или две ячейки имеют одинаковый приоритет,
система предпочитает то место, где такой предмет уже хранится. [Ячейка с настроенным фильтром](cell_workbench.md) считается уже
содержащей указанный предмет, если находится в одной группе приоритета с другими хранилищами. При извлечении система,
наоборот, сначала забирает предметы из хранилища с наименьшим приоритетом. Поэтому при обычном движении ресурсов
высокоприоритетные хранилища заполняются, а низкоприоритетные — опустошаются.
