# МЭ-сундук

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

МЭ-сундук работает как миниатюрная сеть, объединяющая <ItemLink id="terminal" />, <ItemLink id="drive" /> и
<ItemLink id="energy_acceptor" />. Его можно использовать как небольшое сетевое хранилище, но единственный слот для
[ячейки хранения](../items-blocks-machines/storage_cells.md) сильно ограничивает вместимость такой системы.

Основное назначение МЭ-сундука — работа с конкретной установленной в него ячейкой. Встроенный терминал видит только
предметы из этой ячейки, тогда как [устройства](../ae2-mechanics/devices.md) общей сети могут обращаться к ресурсам в любом
[сетевом хранилище](../ae2-mechanics/import-export-storage.md), включая МЭ-сундуки.

У сундука 2 интерфейса, а доступ предметной логистики зависит от стороны. Нажатие по терминалу на верхней грани открывает
встроенный терминал. Через эту грань предметы можно помещать в установленную ячейку, но нельзя извлекать. Нажатие по любой
другой грани открывает интерфейс со слотом ячейки и настройкой приоритета. Предметная логистика может устанавливать и
извлекать саму ячейку только через грань, на которой расположен её слот.

МЭ-сундук поворачивается с помощью <ItemLink id="certus_quartz_wrench" />.

У него есть небольшой внутренний буфер энергии AE. Если сундук не подключён к сети с
[энергетической ячейкой](../items-blocks-machines/energy_cells.md), одновременная передача слишком большого количества
предметов может исчерпать буфер и временно отключить устройство.

Цвет терминала можно изменить с помощью <ItemLink id="color_applicator" />.

## Настройки

МЭ-сундук поддерживает те же настройки, что <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />, но не
поддерживает ячейки <ItemLink id="view_cell" />.

## Индикатор состояния ячейки

Светодиод на ячейке в сундуке показывает её состояние:

| Цвет       | Состояние                                                                                     |
| :--------- | :-------------------------------------------------------------------------------------------- |
| Зелёный    | Ячейка пуста                                                                                   |
| Синий      | В ячейке есть ресурсы                                                                          |
| Оранжевый  | Лимит [типов](../ae2-mechanics/bytes-and-types.md) исчерпан; новый тип добавить нельзя          |
| Красный    | Все [байты](../ae2-mechanics/bytes-and-types.md) заняты; добавить новые предметы нельзя         |
| Чёрный     | Нет энергии либо накопитель не получил [канал](../ae2-mechanics/channels.md)                    |

## Приоритет

Чтобы задать приоритет, нажмите значок гаечного ключа в правом верхнем углу интерфейса со слотом ячейки. Поступающий в
сеть предмет сначала направляется в хранилище с наибольшим приоритетом. Если два хранилища или две ячейки имеют одинаковый
приоритет, предпочтение получает то хранилище, где такой предмет уже есть. В одной группе приоритета ячейка с настроенным
[фильтром](cell_workbench.md) считается уже содержащей указанный в нём предмет. При извлечении сеть, напротив, сначала
забирает предметы из хранилища с наименьшим приоритетом. Поэтому по мере добавления и извлечения ресурсов хранилища с
высоким приоритетом заполняются, а хранилища с низким — опустошаются.
