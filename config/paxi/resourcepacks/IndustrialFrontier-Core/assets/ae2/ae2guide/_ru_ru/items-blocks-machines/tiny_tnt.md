# Крохотный динамит

<BlockImage id="tiny_tnt" scale="8" />

Уменьшенный динамит для небольших взрывов. Особенно полезен при создании пар <ItemLink id="quantum_entangled_singularity" />.

В конфигурации можно отключить разрушение блоков этим динамитом. Так игроки смогут создавать сингулярности без риска повредить постройки — например, на сервере, где обычный динамит и криперы отключены ради защиты от гриферства.
