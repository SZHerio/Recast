Монитор показывает один выбранный тип предмета или жидкости и позволяет взаимодействовать с ним, не открывая интерфейс.

Монитор принимает цвет [кабеля](cables.md), на котором установлен.

Монитор на полу или потолке можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

Мониторы относятся к [кабельным частям](../ae2-mechanics/cable-subparts.md).

# МЭ-монитор хранения

Показывает выбранный предмет или жидкость и доступное количество. Его удобно размещать, например, рядом с фермой.

*Не требует* [канала](../ae2-mechanics/channels.md).

Управление:

*   Щёлкните правой кнопкой мыши с предметом или дважды щёлкните правой кнопкой с ёмкостью жидкости, чтобы выбрать содержимое монитора.
*   Щёлкните правой кнопкой мыши с пустой рукой, чтобы очистить монитор.
*   Нажмите Shift + правую кнопку мыши с пустой рукой, чтобы заблокировать настройку монитора.

# МЭ-монитор преобразования

Монитор преобразования похож на монитор хранения, но через него можно помещать в сеть и извлекать из неё выбранный предмет.

Если выбранный предмет доступен для [автоматического изготовления](../ae2-mechanics/autocrafting.md), но отсутствует в хранилище,
попытка извлечь его откроет окно выбора количества для изготовления.

*Требует* [канал](../ae2-mechanics/channels.md).

Дополнительное управление:

*   Щёлкните левой кнопкой мыши, чтобы извлечь стопку выбранного предмета. Если предмета нет в хранилище, будет создан запрос на его изготовление.
*   Щёлкните правой кнопкой мыши с любым предметом, чтобы поместить его в сеть.
*   Щёлкните правой кнопкой мыши с пустой рукой, чтобы поместить в сеть все экземпляры выбранного предмета из вашего инвентаря.
