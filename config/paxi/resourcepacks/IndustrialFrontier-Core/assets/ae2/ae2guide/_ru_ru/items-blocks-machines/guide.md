# Руководство

<ItemImage id="guide" scale="8" />

### Это руководство, которое вы сейчас читаете. В нём собраны необходимые сведения об AE2.

* Оглавление находится на боковой панели слева.
* На многих страницах есть интерактивные сцены. Если рядом со сценой отображаются кнопки ![Плюс](../assets/diagrams/plus.png)
  и ![Минус](../assets/diagrams/minus.png) для изменения масштаба, камеру можно вращать и перемещать.
  Удерживайте левую кнопку мыши и двигайте указатель для вращения; удерживайте правую кнопку и двигайте указатель для перемещения.
