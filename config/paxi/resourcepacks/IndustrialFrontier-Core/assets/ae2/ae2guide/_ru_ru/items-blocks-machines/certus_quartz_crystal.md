# Кристалл истинного кварца

<ItemImage id="certus_quartz_crystal" scale="4" />

*«Кристаллы истинного кварца обладают уникальным свойством: их кристаллическая решётка способна принимать большое
количество энергии».*

Это один из основных материалов для изготовления блоков, [устройств](../ae2-mechanics/devices.md) и предметов AE2.
Кристаллы выращивают на [цветущем истинном кварце](../ae2-mechanics/certus-growth.md).
