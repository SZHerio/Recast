# Карта памяти

<ItemImage id="memory_card" scale="4" />

Карта памяти копирует и переносит настройки между [устройствами](../ae2-mechanics/devices.md) AE2, а также связывает
[P2P-туннели](p2p_tunnels.md). С её помощью можно переносить в устройства и [карты улучшений](upgrade_cards.md).

- Shift + правая кнопка мыши: скопировать настройки или создать новую частоту связи P2P.
- Правая кнопка мыши: вставить настройки, карты улучшений или частоту связи.
