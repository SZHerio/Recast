# Режущие ножи

<Row>
  <ItemImage id="certus_quartz_cutting_knife" scale="4" />

  <ItemImage id="nether_quartz_cutting_knife" scale="4" />
</Row>

Режущие ножи используются для изготовления <ItemLink id="name_press" /> и <ItemLink id="cable_anchor" />.

Чтобы изготовить именной пресс, щёлкните правой кнопкой мыши с режущим ножом в руке и вставьте металлический слиток.
Введите имя, которое нужно нанести на пластину, затем извлеките готовый пресс.
