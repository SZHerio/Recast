# Ускоритель роста

<BlockImage id="growth_accelerator" p:powered="true" scale="8"/>

Ускоритель роста многократно ускоряет [рост](../ae2-mechanics/certus-growth.md) кристаллов истинного кварца или аметиста,
если установлен рядом с цветущим блоком.

Любопытно, что он *также* ускоряет рост различных растений.

<GameScene zoom="6" interactive={true}>
  <ImportStructure src="../assets/assemblies/growth_accelerator.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Для ручного питания установите <ItemLink id="crank" /> на верхнюю или нижнюю грань и щёлкайте по рукоятке правой кнопкой мыши.

Кабели подключаются только к торцам ускорителя с розовыми флюисовыми вставками.
