label получает или задаёт метку компьютера либо дискеты в подключённом дисководе.

Примеры:
"label get" выведет метку компьютера.
"label get left" выведет метку дискеты в левом дисководе.
"label set "Мой компьютер"" задаст компьютеру метку "Мой компьютер".
"label set left "Мои программы"" задаст дискете в левом дисководе метку "Мои программы".
"label clear" удалит метку компьютера.
"label clear left" удалит метку дискеты в левом дисководе.
