Функции API для побитовых операций (ВНИМАНИЕ: в будущей версии этот API будет удалён. Используйте bit32):
bit.bnot(n)          -- побитовое НЕ (~n)
bit.band(m, n)       -- побитовое И (m & n)
bit.bor(m, n)        -- побитовое ИЛИ (m | n)
bit.bxor(m, n)       -- побитовое исключающее ИЛИ (m ^ n)
bit.brshift(n, bits) -- сдвиг вправо (n >> bits)
bit.blshift(n, bits) -- сдвиг влево (n << bits)
