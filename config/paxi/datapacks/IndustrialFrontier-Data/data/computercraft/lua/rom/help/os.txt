Функции API os (операционной системы):
os.version()
os.getComputerID()
os.getComputerLabel()
os.setComputerLabel()
os.run( environment, programpath, arguments )
os.loadAPI( path )
os.unloadAPI( name )
os.pullEvent( [filter] )
os.queueEvent( event, arguments )
os.clock()
os.startTimer( timeout )
os.cancelTimer( token )
os.sleep( timeout )
os.time( [source] )
os.day( [source] )
os.epoch( [source] )
os.setAlarm( time )
os.cancelAlarm( token )
os.shutdown()
os.reboot()

События API os:
"timer" - завершился отсчёт, запущенный через os.startTimer(). Аргумент - token, возвращённый os.startTimer().
"alarm" - наступило время, переданное в os.setAlarm(). Аргумент - token, возвращённый os.setAlarm().
Введите "help events", чтобы узнать о системе событий.
