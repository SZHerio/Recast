Чтобы изучить язык программирования Lua, посетите http://lua-users.org/wiki/TutorialDirectory.

Для экспериментов с Lua в CraftOS запустите программу "lua" и начните вводить код.
Чтобы создать программу, откройте новый файл через "edit", а затем введите его имя в оболочке для запуска. Если назвать программу "startup" и поместить её в корень компьютера или на диск, она будет запускаться автоматически при включении компьютера.

Чтобы завершить зациклившуюся программу, удерживайте Ctrl+T в течение 1 секунды.
Чтобы быстро выключить компьютер, удерживайте Ctrl+S в течение 1 секунды.
Чтобы быстро перезагрузить компьютер, удерживайте Ctrl+R в течение 1 секунды.

Чтобы узнать о доступных API программирования, введите "apis" или "help apis".
Если вам нужна помощь, посетите форум http://www.computercraft.info/ - там есть советы и учебные материалы.
