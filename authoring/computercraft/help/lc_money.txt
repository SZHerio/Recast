Функции API LC Money:
lc_money.addMoney( val1, val2 )
  Складывает два денежных значения и возвращает результат
lc_money.subtractMoney( val1, val2 )
  Вычитает второе денежное значение из первого и возвращает результат
lc_money.percentageOfMoney( val, percentage )
  Вычисляет указанный процент от денежного значения и возвращает результат
lc_money.multiplyMoney( val, mult )
  Умножает денежное значение на множитель и возвращает результат
lc_money.readInventoryValues( table )
  Определяет денежную стоимость предметов из указанной таблицы.
  Принимает как запись одного предмета, так и таблицу с несколькими записями.
  Может читать содержимое других периферийных устройств типа «инвентарь» из таблицы, которую возвращает их функция "list"

Денежные значения принимаются строками в формате MoneyValueArgument (например, "coin;5-lightmanscurrency:coin_copper")
Также принимаются таблицы данных, возвращённые другими периферийными устройствами Lightman's Currency, включая результаты перечисленных выше методов
