Функция os.pullEvent() приостанавливает программу до появления системного события. Первым возвращается имя события, затем его аргументы.

Некоторые возможные события:
"char" — на клавиатуре введён текст. Аргумент — введённый символ.
"key" — нажата клавиша. Аргументы — код клавиши и признак повторного нажатия. Сравните код со значениями API keys, чтобы определить клавишу.
"key_up" — клавиша отпущена. Аргумент — числовой код клавиши. Сравните его со значениями API keys, чтобы определить клавишу.
"paste" — вставлен текст с клавиатуры пользователя. Аргумент — строка вставленного текста.

События только для продвинутых компьютеров:
"mouse_click" — пользователь щёлкнул кнопкой мыши. Аргументы: button, xPos, yPos.
"mouse_drag" — пользователь переместил мышь с зажатой кнопкой. Аргументы: button, xPos, yPos.
"mouse_up" — пользователь отпустил кнопку мыши. Аргументы: button, xPos, yPos.
"mouse_scroll" — пользователь прокрутил колёсико мыши. Аргументы: direction, xPos, yPos.

Другие API и периферийные устройства создают собственные события. Подробности приведены на соответствующих страницах справки.
