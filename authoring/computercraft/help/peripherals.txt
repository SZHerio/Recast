Программа "peripherals" выводит список всех периферийных устройств, доступных этому компьютеру.
Периферийные устройства — это внешнее оборудование, с которым компьютеры и черепахи CraftOS работают через API peripheral.
Введите "help peripheral", чтобы узнать об API peripheral.
Введите "help drives", чтобы узнать о дисководах.
Введите "help modems", чтобы узнать о модемах.
Введите "help monitors", чтобы узнать о мониторах.
Введите "help printers", чтобы узнать о принтерах.
