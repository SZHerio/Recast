Функции API GPS:
gps.locate( timeout )

Функция locate отправляет сигнал ближайшим серверам GPS и ожидает ответов до истечения timeout. Если ответов достаточно, чтобы определить положение этого компьютера, функция возвращает координаты x, y и z; иначе она возвращает nil. Если положения серверов GPS настроены неверно, результат будет неточным.
