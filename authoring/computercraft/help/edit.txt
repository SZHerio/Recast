edit — текстовый редактор для создания и изменения программ и текстовых файлов. Создав программу в edit, введите её имя в оболочке, чтобы запустить её. Можно открыть в edit любую встроенную программу и посмотреть, как она устроена.

Пример:
"edit hello" откроет для редактирования файл с именем "hello".
