Функции API commands:
commands.exec( command )
commands.execAsync( command )
commands.list()
commands.getBlockPosition()
commands.getBlockInfo( x, y, z )
commands.getBlockInfos( minx, miny, minz, maxx, maxy, maxz )

API commands также позволяет вызывать команды напрямую, например:
commands.say( "Привет, мир!" )
commands.give( "dan200", "minecraft:diamond", 64 )
Это работает с любой командой. Чтобы выполнить её асинхронно, используйте "commands.async" вместо "commands".

API commands доступен только на командных компьютерах.
Документация по всем командам: https://minecraft.wiki/w/Commands
